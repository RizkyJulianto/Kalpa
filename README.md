# 🕯️ Kalpa — Slow Living & Botanical Aromatherapies

> **"Screens Never Dim, Minds Never Rest."**  
> An editorial, slow-living landing page crafted to deliver a mindful and sensory digital experience through artisanal natural aromatherapy candles.

---

## 🌿 About The Project

**Kalpa Living** is an interactive landing page that emphasizes storytelling and sensory web design. It invites users to pause and unplug from the digital noise through warm visual narratives, an interactive scent finder, and soothing, synchronized ambient audio.

### ✨ Key Features

- 🎧 **Synchronized Ambient Audio**: Real-time synced background audio (*rain & crackling fire*) seamlessly integrated across sections (Hero & Philosophy).
- 🧭 **Interactive Scent Finder**: A mood-based interactive quiz that recommends tailored candle scents.
- 📱 **Fully Responsive & Clean Typography**: Adaptive layout across all viewports featuring breathable, editorial typography.
- 💬 **Direct WhatsApp Order CTA**: Instant order integration with dynamic, product-specific pre-filled messages.
- ✉️ **Direct Mail/Newsletter**: Quick email subscription flow integrated directly with Gmail Compose.
- ❓ **Collapsible FAQ Accordion**: Concise, interactive product care guides and specifications.

---

## 🛠️ Tech Stack

- **Markup & Structure**: HTML5 Semantic Elements
- **Styling**: Tailwind CSS
- **Interactivity**: Vanilla JavaScript
- **Icons**: Lucide Icons

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RizkyJulianto/Kalpa.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Kalpa
   ```
3. **Install dependencies::**
   ```bash
   npm install
   ```
3. **Run Project:**
    ```bash
   npm run dev
   ```
   Open index.html directly in your browser, or launch it with the Live Server extension in VS Code.
